## O que é o STCP Gemini API? 

O STCP Gemini API é o serviço que utiliza a arquitetura REST do módulo STCP Gemini, permitindo gerenciar as configurações do STCP Gemini Server a partir de requisições HTTP. Sua função é facilitar o gerenciamento das caixas postais e permitir que sejam manipuladas através da integração com soluções dos clientes.
 
O STCP Gemini API permite a manipulação de:
 
- Servidores (Instâncias)
- Usuários
- Serviços de Rede
- Agendamentos
- Tipos de Arquivos

> [!NOTE]
> Por se tratar de um serviço que segue as metodologias REST, os métodos HTTP (`POST`, `GET`, `PUT` e `DELETE`) refletem os métodos CRUD (Create, Retrieve, Update e Delete) do módulo.
