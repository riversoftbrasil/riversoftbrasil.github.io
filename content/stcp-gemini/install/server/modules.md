## Sobre os módulos

Alguns módulos da plataforma podem ser utilizados em conjunto com o STCP Gemini Server para estender os recursos de processamento, automação e tratamento de arquivos do ambiente.

Esses módulos possuem funções específicas e podem ter requisitos próprios de instalação, configuração e execução.

### STCP Gemini Rename

O **STCP Gemini Rename (STCPRen)** é um módulo utilizado em conjunto com o STCP Gemini Server para automatizar o tratamento e o direcionamento de arquivos.

> [!IMPORTANT]
> O STCP Gemini Rename deve ser instalado no mesmo servidor ou imagem de container onde o STCP Gemini Server está instalado.
